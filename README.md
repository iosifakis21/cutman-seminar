# Σεμινάριο Cutman & Hand Wrapping — 3D demo

Landing page for the Cutman & Hand Wrapping seminar by Michalis Sioulis
(under the aegis of the World Cutman Association), Dynamo Academy, Μεταμόρφωση.

A single self-contained `index.html`: three.js r128 (from cdnjs) renders the corner kit
floating in zero gravity. Scroll flies the camera through it; hover or tap an object to
see what it's for. All textures and the environment map are generated procedurally.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Publish on GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
